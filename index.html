ระบบบริหารจัดการการเงินส่วนบุคคล
Finora — Pastel Finance Architecture

ออกแบบและพัฒนาด้วยเทคโนโลยีเว็บสมัยใหม่ ธีมสีชมพูพาสเทลระดับพรีเมียม ตอบโจทย์ผู้ใช้งานที่ต้องการบันทึกรายรับรายจ่ายอย่างมีความสุข รองรับการ Deploy บน Vercel พร้อมระบบฐานข้อมูล Supabase และการสร้างรายได้ (Monetization)

🎯 วัตถุประสงค์และจุดเด่นของระบบ

  • จดบันทึกได้ง่ายและรวดเร็ว: ระบบ Quick Action และปุ่มลัด รองรับการแยกหมวดหมู่และช่องทางชำระเงิน
  • Dashboard & กราฟวิเคราะห์สมบูรณ์แบบ: ใช้ Chart.js แสดงผลเส้นแนวโน้มกระแสเงินสด สัดส่วนรายจ่าย และการใช้จ่ายรายวัน
  • ระบบแจ้งเตือนอัจฉริยะ (Smart Alerts): เตือนเมื่อใช้จ่ายใกล้หรือเกินงบประมาณที่กำหนดไว้ เพื่อป้องกันการใช้เงินเกินตัว
  • Monetization & Back-office: ระบบเก็บค่าสมาชิก 3 ระดับ พร้อมหน้าต่างจำลองชำระเงิน และระบบตั้งค่าหลังบ้าน
  • Ready for Vercel & Supabase: ออกแบบให้เป็น Single Page Application น้ำหนักเบา ขึ้นคลาวด์ได้ทันที พร้อม Dual-Mode Fallback

🏗️ สถาปัตยกรรมและเทคโนโลยีที่ใช้

🎨 Frontend & UI Design: Vanilla HTML5, Vanilla CSS3 (Pastel Pink Glassmorphism), Prompt/Inter Typography, Micro-animations
📊 Data Visualization: Chart.js (Area Spline, Doughnut Chart, Rhythm Bar Chart)
⚡ Backend & Database: Supabase (PostgreSQL 15, Row Level Security, Supabase Auth) + Local Storage Fallback
🚀 Cloud Deployment: Vercel Platform พร้อมไฟล์คอนฟิก vercel.json
