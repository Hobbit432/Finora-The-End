# Finora (ฟิโนร่า) — ระบบบริหารจัดการการเงินส่วนบุคคล
> **เว็บแอปพลิเคชันสำหรับบันทึกและจัดการรายรับ–รายจ่ายส่วนบุคคล ในธีมสีชมพูพาสเทลระดับพรีเมียม (Pastel Pink) พร้อมเชื่อมต่อ Supabase Database และพร้อม Deploy บน Vercel ทันที**

## 🌸 จุดเด่นและความสามารถของระบบ

1. **Dashboard แสดงภาพรวมทางการเงินแบบเรียลไทม์**:
   - ยอดเงินคงเหลือสุทธิ (Net Balance), รายรับรวม, รายจ่ายรวม, อัตราการออมเงิน (%)
   - กราฟแนวโน้มกระแสเงินสดสะสม (Cashflow Trend Spline) ด้วย Chart.js
   - กราฟสัดส่วนรายจ่ายตามหมวดหมู่ (Pastel Donut Chart)
   - กราฟแท่งแสดงการใช้จ่ายรายวัน (Daily Spending Rhythm Bar Chart)
2. **ระบบบันทึกรายรับ–รายจ่าย (Transaction Engine)**:
   - สลับประเภท รายรับ / รายจ่าย ได้อย่างรวดเร็ว
   - กำหนดหมวดหมู่, วันที่, ช่องทางชำระเงิน (พร้อมเพย์, บัตรเครดิต, โอนธนาคาร, เงินสด)
   - ค้นหาแบบทันใจ และตัวกรองข้อมูลหลายมิติ
3. **ระบบจัดการงบประมาณ & แจ้งเตือนอัจฉริยะ (Budgeting & Smart Alerts)**:
   - กำหนดงบประมาณรายหมวดหมู่ และงบรวมประจำเดือน
   - แถบความคืบหน้างบประมาณ (Progress Bar)
   - แจ้งเตือนอัตโนมัติเมื่อใช้จ่ายใกล้หรือเกินงบประมาณ (70%, 80%, >=90% และ >100%)
4. **วิเคราะห์พฤติกรรมการใช้จ่ายเบื้องต้น (Financial Insights)**:
   - วิเคราะห์หมวดหมู่ที่ใช้เงินมากที่สุด
   - ประเมินคะแนนสุขภาพทางการเงิน (Financial Health Score)
   - ให้คำแนะนำการออมเงินอัจฉริยะ
   - ส่งออกข้อมูลเป็นไฟล์ CSV สำหรับเปิดใน Excel หรือสำรองข้อมูล
5. **ระบบสมาชิกและเก็บเงินผู้ใช้ (Monetization & Subscriptions)**:
   - 3 แพ็กเกจ: Starter (ฟรี), Finora Plus (99 บ./เดือน), Finora Pro (199 บ./เดือน)
   - หน้าต่างจำลองชำระเงินผ่าน QR Code PromptPay พร้อมระบบอัปเกรดสถานะบัญชีทันที
6. **ระบบตั้งค่าหลังบ้าน (Back-Office Admin)**:
   - จัดการเพิ่ม/ลบหมวดหมู่ประจำระบบ
   - หน้าเชื่อมต่อ Supabase Database (Project URL & Anon Key)
   - คำสั่ง SQL Schema พร้อมปุ่มคัดลอกใน 1 คลิก
   - ปุ่มรีเซ็ตข้อมูลจำลองสำหรับนำเสนอ Demo
7. **ภาพสื่อนำเสนอ (Presentation Showcase)**:
   - ภาพกราฟิก 3D Isometric Pastel Pink เฉพาะตัว
   - หน้า Showcase สรุปสถาปัตยกรรมระบบสำหรับใช้ในการนำเสนอ

## 🚀 วิธีการเปิดใช้งานบนเครื่องของคุณ (Local Development)

### ทางเลือกที่ 1: เปิดด้วย Python (มีติดตั้งอยู่ในเครื่องแล้ว)
```bash
python -m http.server 3000
```
เปิดบราวเซอร์ไปที่: `http://localhost:3000`

## ⚡ การเชื่อมต่อ Supabase Database

1. สมัครหรือเข้าสู่ระบบที่ [supabase.com](https://supabase.com) แล้วสร้างโปรเจกต์ใหม่
2. ไปที่เมนู **SQL Editor** ใน Supabase แล้วเปิดไฟล์ [`supabase_schema.sql`](supabase_schema.sql) คัดลอกคำสั่งทั้งหมดไปวางแล้วกด **Run**
3. ไปที่เมนู **Project Settings > API** คัดลอก:
   - **Project URL**
   - **anon public API Key**
4. เปิดเว็บ Finora ไปที่แท็บ **⚙️ หลังบ้าน (Admin)** แล้ววาง URL และ Key ลงในช่อง จากนั้นกด **บันทึกการเชื่อมต่อ**
5. ระบบจะสลับไปบันทึกและซิงค์ข้อมูลบน Supabase Cloud โดยอัตโนมัติ!

## 🌐 วิธีนำขึ้นออนไลน์ด้วย Vercel (Deploy to Vercel)

โปรเจกต์นี้มีไฟล์ `vercel.json` เตรียมไว้ให้พร้อมแล้ว สามารถ Deploy ได้ง่ายๆ 2 วิธี:

### วิธีที่ 1: Deploy ผ่าน GitHub (แนะนำ)
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub Repository ของคุณ
2. เข้าสู่ระบบที่ [vercel.com](https://vercel.com) แล้วคลิก **Add New... > Project**
3. เลือก Repository ที่คุณเพิ่งอัปโหลด แล้วกด **Deploy**
4. เว็บไซต์ของคุณจะออนไลน์ได้ทันทีภายใน 30 วินาที

### วิธีที่ 2: Deploy ผ่าน Vercel CLI
```bash
npx vercel
```
ทำตามขั้นตอนบนหน้าจอเพื่อ Deploy โปรเจกต์ขึ้น Vercel ได้ทันที
